# Лендинг «Умный Лис» — сегмент «Альтернатива очным занятиям»

Одностраничный посадочный сайт для родителей, которым неудобны очные кружки/репетиторы
(дорога, расписание, стоимость). Цель страницы — довести посетителя до перехода на
основной образовательный сайт.

Чистый HTML/CSS/JavaScript, без сборщиков и фреймворков. Готов к загрузке на любой
обычный хостинг как есть.

## 1. Какие файлы входят в проект

```
landing-doma/
├── index.html        — вся структура и тексты страницы
├── css/
│   └── styles.css    — вся дизайн-система и адаптивность
├── js/
│   └── script.js     — меню, FAQ, демо-задания, анимации, трекинг событий
├── favicon.svg        — иконка вкладки (лисёнок)
├── robots.txt
└── README.md          — этот файл
```

Отдельной папки `assets/` нет — все визуальные элементы (иконки, мокап карточки
задания, декоративные фигуры) сделаны на CSS/SVG/эмодзи, без внешних изображений.

## 2. Как открыть сайт локально

Файл `index.html` можно просто открыть в браузере двойным кликом — сайт полностью
статический, сервер для локального просмотра не обязателен.

Если браузер ограничивает какие-то возможности при открытии файла напрямую (`file://`),
можно поднять простой локальный сервер из папки проекта:

```bash
cd landing-doma
python3 -m http.server 8000
```

и открыть `http://localhost:8000` в браузере.

## 3. Как разместить сайт на обычном хостинге

Загрузите содержимое папки `landing-doma/` (файл `index.html` и папки `css/`, `js/`
вместе с `favicon.svg`, `robots.txt`) в корень домена или подпапку через FTP/файловый
менеджер хостинга. Дополнительная настройка сервера, база данных или сборка не нужны.

## 4. Где изменить URL основного сайта

Сейчас везде используется заглушка `https://example.com/`. Два места для замены:

- **В `index.html`** — каждая CTA-кнопка задана как `href="https://example.com/"`
  (в шапке, в hero, у демо-заданий, в финальном блоке). Проще всего сделать
  find & replace по всему файлу: `https://example.com/` → ваш реальный адрес.
- **В `js/script.js`** — константа в самом начале файла:
  ```js
  var MAIN_SITE_URL = 'https://example.com/'; // ЗАМЕНИТЬ НА URL ОСНОВНОГО САЙТА
  ```
  Она используется только для событий аналитики (какая ссылка была целью клика),
  на сами переходы не влияет — но её тоже стоит обновить для точности данных.

Также замените `https://example.com/` в `<link rel="canonical">`, `og:url` и в
`robots.txt` (строка `Sitemap:`) на реальный адрес этой страницы после публикации.

## 5. Где изменить название проекта

Название «Умный Лис» — рабочее и встречается в нескольких местах `index.html`:

- `<title>` и мета-теги в `<head>`;
- логотип в шапке (`<span class="logo__text">`);
- подпись в футере;
- тексты в JSON-LD (`<script type="application/ld+json">`).

Замените текст «Умный Лис» на финальное название проекта во всех перечисленных местах.

## 6. Где поменять цвета

Все цвета вынесены в CSS-переменные в начале `css/styles.css`, в блоке `:root`:

```css
:root {
  --bg: #FFF9F1;
  --surface: #FFFFFF;
  --text: #263238;
  --muted: #667085;
  --orange: #F28C38;
  --orange-dark: #DB7125;
  --blue: #DDEFFB;
  --mint: #DDF3E6;
  --yellow: #FFE8A3;
  ...
}
```

Изменение значений в этом одном месте поменяет цвет по всей странице — отдельно
искать цвета по каждому блоку не нужно.

## 7. Как заменить иллюстрацию лисёнка

Сейчас маскот нарисован простыми SVG-фигурами прямо в `index.html` (в шапке и в
mock-карточке hero-блока) — специального файла-изображения нет, поэтому страница
не зависит от подгрузки картинки.

Когда появится финальная иллюстрация маскота:

1. Положите файл, например, `assets/fox-hero.webp`, в новую папку `assets/`.
2. В `index.html` замените блок `<svg class="mock-card__fox">...</svg>` (и/или
   `<svg class="logo__icon">...</svg>`) на `<img src="assets/fox-hero.webp" alt="Лисёнок — маскот проекта">`.
3. При необходимости поправьте размеры через CSS-классы `.logo__icon` и `.mock-card__fox`.

## 8. Где подключить Яндекс Метрику / аналитику

В `js/script.js` есть функция `trackEvent(eventName, params)` — через неё уже проходят
все ключевые события: клики по CTA (`hero_cta_click`, `header_cta_click`,
`example_cta_click`, `final_cta_click`), ответы в демо-заданиях (`demo_task_answer`)
и открытие вопросов FAQ (`faq_open`). Сейчас она просто пишет события в консоль
браузера (`console.log`).

Чтобы подключить реальную аналитику:

1. Добавьте код счётчика Яндекс Метрики / Google Analytics в `<head>` файла `index.html`.
2. В `js/script.js` внутри функции `trackEvent` раскомментируйте соответствующие строки:
   ```js
   // if (typeof ym === 'function') { ym(XXXXXXXX, 'reachGoal', eventName, params); }
   // if (typeof gtag === 'function') { gtag('event', eventName, params || {}); }
   ```
   и укажите номер счётчика вместо `XXXXXXXX`.

## 9. Где изменить SEO title и description

В `<head>` файла `index.html`:

```html
<title>Развивающие занятия для детей онлайн — дома и в своём темпе</title>
<meta name="description" content="...">
```

Там же рядом — Open Graph теги (`og:title`, `og:description`, `og:url`) и
JSON-LD разметка (`WebSite` и `FAQPage`) — их тоже стоит обновить при изменении
названия проекта или домена.
